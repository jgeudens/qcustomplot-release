# qcustomplot-release

This repo tracks the releases from [QCustomplot](https://www.qcustomplot.com/). The official releases are generated with a script that combines all source files and all header files.

All credits for QCustomplot go to [DerManu](https://www.qcustomplot.com/).

CMakeList.txt is added and maintained by [jgeudens](https://github.com/jgeudens/)
